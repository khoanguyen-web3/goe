# GOE Alliance

Static landing page for the GOE Alliance (Global On-chain Economy Alliance).

`v2_build.py` regenerates the HTML (`index.html`, `ledger.html`, `blog.html`, `article.html`, `about.html`, `activities.html`, and the posts under `blog/`) from `blog_posts.json` and the assets in `img/`.

`about.html` and `activities.html` are intentionally disabled in the navigation (shown as coming soon, with no URL) and excluded from deploy for now.
